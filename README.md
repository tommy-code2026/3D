# 101 日常漫遊

以 golf.png 為視覺參考的第一人稱單人探索遊戲。101、球場與樹木由 Blender 建模，遊戲場景、角色動畫與互動由 Three.js 製作，Cannon-es 負責行走、重力、碰撞與推桿物理。

## 開啟

以 Chrome 或 Edge 開啟 [Golf_3D.html](Golf_3D.html)，不需要本機伺服器。模型已嵌入 HTML；Three.js、Cannon-es、Lucide 與字型由 CDN 載入，因此需要網路連線。

## 生活圈

- 101 廣場：遇見居民，與朋友聊天。
- 信義購物街：逛街人群、花店、選物店，以及能購買咖啡的店主。
- 綠意共享辦公室：居民會在桌前工作，玩家可以協助完成三項待辦。
- 湖畔景觀橋：可走上斜坡與橋面，觀賞風景及遇見攝影師。
- 東側高爾夫球場：球友揮桿，玩家可向教練挑戰力道控制推桿。
- 午後遊戲草坪：居民一起玩遊戲，玩家可以挑戰六組翻牌配對。

首次探索區域、完成推桿、配對、辦公任務及全區探索可獲得獎勵。活動獎勵只發放一次，但可重玩。金幣、物品和探索紀錄會盡可能儲存在同一瀏覽器的 localStorage；清除瀏覽資料、變更檔案位置或瀏覽器限制可能使紀錄重設。

這是風格化概念場景，不是實測台北地圖。居民是本機動畫 NPC，聊天採預先設計的對話，並非真人連線或生成式 AI。開放式工作室可進入；101 塔樓與一般建築目前為有碰撞的外觀模型，沒有電梯與逐樓層室內。

## 重新產生

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python .\create_golf_3d.py -- .\golf.png .\Golf_3D.html
```

- [create_golf_3d.py](create_golf_3d.py)：Blender 基礎場景建模與輸出。
- [golf_game_template.html](golf_game_template.html)：遊戲程式與介面，模型資料由產生器嵌入。
- [Golf_3D.blend](Golf_3D.blend)：可編輯的 Blender 基礎建模資產。
- [Golf_3D.glb](Golf_3D.glb)：基礎場景交換格式；人物、商店、道路加建與互動在 HTML 執行時建立。
